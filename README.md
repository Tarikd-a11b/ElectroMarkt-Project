
ElectroMarkt - E-Commerce Web Application
Project Overview
This project was developed as the final assignment for the Web Programming course. The primary objective was to strengthen core web development skills by building a functional e-commerce platform for electronic goods.

ElectroMarkt provides a seamless shopping experience where customers can browse electronic products and meet their needs quickly and efficiently.

 Tech Stack
Frontend: HTML5, CSS3 (Custom styling and responsive design).

Scripting: JavaScript (Dynamic content and UI interactions).

Backend & Database: Firebase (Used for real-time data management and hosting).

 Key Features
User-Friendly Interface: A clean, modern design focused on the electronics niche.

Dynamic Product Listing: Real-time data fetching powered by Firebase technology.

Responsive Design: Fully compatible with mobile and desktop browsers.
